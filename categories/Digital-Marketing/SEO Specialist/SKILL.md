## Overview

The SEO Specialist skill provides comprehensive capabilities for optimizing websites to rank higher in search engine results, driving qualified organic traffic that converts. It covers technical SEO, content strategy, link building, local/international SEO, and analytics.

## Quick Start

```bash
# Essential SEO toolkit setup
# 1. Verify Google Search Console property
# 2. Connect Ahrefs/SEMrush for keyword research
# 3. Run Screaming Frog technical audit
# 4. Set up rank tracking for target keywords
# 5. Configure GA4 for conversion tracking
```

## Configuration

Key options in `config/settings.yaml`:

```yaml
tools:
  primary_seo_tool: "ahrefs"  # ahrefs, semrush, moz
  crawler: "screamingfrog"
  rank_tracker: "ahrefs"
  analytics: "ga4"

targets:
  primary_market: "US"
  languages: ["en"]
  target_keywords_count: 1000

audit:
  frequency: "quarterly"
  depth: "comprehensive"  # comprehensive, focused
  core_web_vitals: true

content:
  min_word_count: 1500
  target_reading_level: "8th grade"
  schema_types: ["Article", "FAQ", "Product", "LocalBusiness"]

link_building:
  target_dr_min: 40
  outreach_per_month: 50
  linkable_asset_types: ["study", "calculator", "guide", "template"]
```

## Troubleshooting

| Issue | Cause | Solution |
|-------|-------|----------|
| Rankings dropped suddenly | Algorithm update or penalty | Check GSC for manual actions; analyze update impact |
| Pages not indexing | Crawl budget, noindex, canonical | Check GSC coverage; fix technical issues; request indexing |
| Low conversion from organic | Intent mismatch, poor UX | Analyze search intent; improve content and CTAs |
| Toxic backlinks | Spam links, negative SEO | Disavow file; monitor; focus on quality acquisition |
| Core Web Vitals failing | Large assets, blocking JS, slow server | Optimize images; defer JS; upgrade hosting/CDN |
