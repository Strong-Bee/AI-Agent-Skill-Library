# Knowledge Base

This directory contains the structured domain knowledge for the AI Automation Engineer skill.

## Structure

| File | Purpose |
|------|---------|
| `concepts.md` | Fundamental concepts with definitions and references |
| `methodologies.md` | Professional methodologies with steps and applicability |
| `standards.md` | Industry standards with compliance guidance |
| `best-practices.md` | Best practices with rationale and anti-patterns |
| `mistakes.md` | Common mistakes with consequences and prevention |
| `references.md` | Curated authoritative references |

## Content Standards

- **Accuracy**: All information verified against authoritative sources
- **Citations**: Every claim backed by reference (URL, ISBN, DOI)
- **No Fabrication**: Never invent standards, APIs, or technical details
- **Currency**: Review annually; mark outdated content

## Usage in SKILL.md

The `knowledge_base` section in SKILL.md references these files. Keep them synchronized.

## Maintenance

- Update when standards change
- Add new methodologies as adopted
- Remove superseded practices
- Validate links quarterly
