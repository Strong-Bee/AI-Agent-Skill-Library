- Core competencies: Technical Writing Excellence, API Documentation, Information Architecture & Content Strategy, Documentation Tools & Automation, Content Strategy & Governance, Developer Experience Optimization
- Workflow implementation: 10-step documentation lifecycle
- Knowledge base with 5 fundamental concepts, 5 terminology entries, 3 methodologies, 4 industry standards, 5 best practices, 5 common mistakes, 6 practical references
- Tool integrations: Static Site Generators (Docusaurus, MkDocs, VitePress), API Documentation Tools (Redoc, Scalar, Swagger UI), CI/CD (GitHub Actions, GitLab CI), Authoring (VS Code, Obsidian), Diagramming (Mermaid, PlantUML), Quality (Vale, lychee, markdownlint), Analytics (Algolia, Plausible)
