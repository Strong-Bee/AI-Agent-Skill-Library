## Overview

Authoritative terminology definitions for consistent use across all skills in the library.

---

## Core Concepts

| Term | Definition |
|------|------------|
| **Skill** | A self-contained, reusable module that enables an AI agent to perform a specific professional role or task |
| **Skill ID** | Unique kebab-case identifier (e.g., `ai-agent-developer`) |
| **Category** | One of 12 professional domains organizing skills |
| **Competency** | A measurable professional capability provided by a skill |
| **Workflow** | The 10-step standard process every skill follows |
| **Knowledge Base** | Structured domain knowledge (concepts, standards, methodologies, etc.) |
| **Platform** | An AI agent runtime (Claude Code, OpenCode, Cursor, etc.) |
| **Adapter** | Platform-specific integration layer for a skill |
| **Metadata** | Machine-readable skill specification in SKILL.md frontmatter |

## AI & Automation Terms

| Term | Definition |
|------|------------|
| **Agent** | An AI system that can perceive, reason, and act autonomously |
| **Multi-Agent System** | Multiple agents collaborating to achieve a goal |
| **MCP (Model Context Protocol)** | Standard for connecting AI models to external tools/data |
| **RAG (Retrieval-Augmented Generation)** | Combining retrieval with generation for grounded outputs |
| **Prompt Engineering** | Designing inputs to elicit desired model behavior |
| **Tool Use / Function Calling** | Model invoking external functions |
| **Context Window** | Maximum tokens the model can process |
| **Token** | Basic unit of text processing (~4 chars English) |
| **Hallucination** | Model generating false/unsupported information |
| **Grounding** | Anchoring outputs in verifiable sources |
| **Evaluation (Evals)** | Systematic testing of model outputs |
| **Few-Shot / Zero-Shot** | Examples provided in prompt |
| **Chain of Thought** | Step-by-step reasoning in output |
| **Agentic Workflow** | Workflow with autonomous decision points |
